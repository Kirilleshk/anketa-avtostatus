# Анкета для заказчика — как запустить

Одна страница `index.html`, без сервера и без сторонних библиотек. Клиент заполняет её с телефона или компьютера, ответы сохраняются у него на устройстве, а по кнопке «Сохранить и отправить» приходят вам в Telegram: сообщение, файл ответов (`.txt`), копия в `.json` и все прикреплённые документы.

## 1. Создайте бота (2 минуты)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя, например «Анкета Авто-Статус».
2. BotFather пришлёт **токен** вида `123456789:AAH...`.
3. Откройте своего нового бота и нажмите **«Старт»** (`/start`) — без этого бот не сможет вам писать.

## 2. Узнайте свой chat_id

Откройте в браузере (подставьте токен):

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":123456789` — это число и есть chat_id. Если ответ пустой — ещё раз напишите боту и обновите страницу.

## 3. Разместите страницу

**Уже опубликовано:** https://kirilleshk.github.io/anketa-avtostatus/ (репозиторий `Kirilleshk/anketa-avtostatus`, ветка `main`, GitHub Pages).
Чтобы обновить анкету, сделайте коммит изменённого `index.html` в этой папке и `git push`. Через минуту новая версия будет на сайте. Черновики ответов, которые клиент уже начал заполнять, сохранятся.

Подойдёт любой адрес с https:

- **GitHub Pages** (бесплатно): новый репозиторий → загрузите `index.html` → Settings → Pages → Deploy from branch → `main` / `root`. Адрес будет вида `https://<логин>.github.io/<репозиторий>/`.
- Или папка на любом вашем хостинге.

Токен в файле не хранится, поэтому выкладывать `index.html` в открытый репозиторий безопасно.

## 4. Соберите ссылку для клиента

```
https://<адрес страницы>/#bot=<ТОКЕН>&chat=<CHAT_ID>
```

При первом открытии страница запоминает настройки на устройстве клиента и убирает их из адресной строки.

## 5. Проверьте сами

Откройте ссылку на своём телефоне, ответьте на пару вопросов, прикрепите любой файл и нажмите «Сохранить и отправить». В Telegram должны прийти сообщение, два файла с ответами и ваш файл. Ваши тестовые ответы хранятся только на вашем телефоне — у клиента анкета откроется пустой.

## После получения ответов

В @BotFather выполните `/revoke` для этого бота — токен перестанет работать, и ссылка больше ничего не отправит.

## Что важно знать

- Клиенту отправляйте **ссылку**, а не сам файл `index.html`. Если открыть файл на телефоне из мессенджера или файлового менеджера, встроенный просмотрщик не запускает скрипты, и анкета не работает: вместо неё будет подсказка «Анкета не открылась».
- Проверить на своём телефоне до публикации можно через локальную сеть: запустите на компьютере простой сервер в папке `anketa` и откройте на телефоне `http://<IP компьютера>:<порт>/`. Телефон и компьютер должны быть в одной сети Wi‑Fi, а брандмауэр Windows должен пропускать этот сервер.
- Токен виден тому, у кого есть ссылка. Бот умеет только писать вам, но ссылку не публикуйте.
- Файлы — до 50 МБ каждый (ограничение Telegram). Прикреплённые файлы не сохраняются в черновике: их прикрепляют прямо перед отправкой.
- Если у клиента не работает Telegram, на последнем шаге есть кнопка «Скачать ответы файлом» — файл можно прислать в любом мессенджере.
- Ответы содержат сведения о сотрудниках школы (ФИО, образование, стаж) — те же, что по закону публикуются на сайте.
